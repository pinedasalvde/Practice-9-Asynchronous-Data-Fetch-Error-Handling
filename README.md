# Practice 9: Asynchronous Data Fetch and Error Handling

Open `index.html` in a browser with an internet connection to view example users
from the public [JSONPlaceholder API](https://jsonplaceholder.typicode.com/).
Use **Reload users** to fetch the data again. If the request fails or the
response is invalid, the page displays an error and allows you to retry.

Run the automated checks with `node --test script.test.js` (Node.js 18 or later).
